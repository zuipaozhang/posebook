# 📸 灵感图库 · 拍照姿势参考（PoseBook）

> 一个纯前端 PWA：把你在各平台收藏的"好看照片"存进**自己的 GitHub 仓库**，
> 按 **服饰 / 场景 / 动作 / 角度 / 构图 / 光线** 六维打标签，
> 拍摄前在手机上搜索"明制汉服 + 古建"，立刻弹出所有可参考的姿势。

- **手机端上传存图**：选相册照片 → 自动压缩 → 点标签 → 一键存入仓库
- **六维快速打标**：点一下就打上"回眸 / 45度 / 逆光"这类标签
- **组合检索**：多标签 AND + 关键词搜索
- **评分与备注**：给参考图打分、记拍摄要点
- **数据自主**：照片（压缩图）与标签都存在你自己的 GitHub 仓库，随时可导出备份

## 一、部署（只需 10 分钟，一次搞定）

### 第 1 步：创建 GitHub 仓库

1. 打开 [github.com/new](https://github.com/new)
2. **Repository name** 填：`posebook`
3. 选 **Public**（公开仓库；私有仓库无法使用 GitHub Pages 免费托管）
4. 勾选 **Add a README file**（让仓库至少有一个文件）
5. 点 **Create repository**

### 第 2 步：生成访问令牌（Fine-grained PAT）

1. 打开 [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)
2. **Token name**：填 `posebook`
3. **Expiration**：选 90 天或 No expiration
4. **Repository access**：选 **Only select repositories** → 勾选 `posebook`
5. **Permissions** → 找到 **Contents** → 选 **Read and write**
6. 点 **Generate token**，**立即复制**生成的 `github_pat_...`（只显示一次！）

### 第 3 步：上传网站文件（约 3 分钟，二选一）

**方式一：一键脚本（推荐）**
双击项目目录里的 **`一键上传到GitHub.bat`** → 按提示输入 GitHub 用户名、仓库名、令牌 → 自动上传全部文件，完成后脚本会提示你下一步。令牌只在你的电脑本地使用，只发送给 GitHub 官方 API。

**方式二：网页手动上传**
仓库页面 → **Add file → Upload files** → 把项目里的 `index.html`、`app.js`、`style.css`、`manifest.webmanifest`、`sw.js`、`README.md`、`icons/` 文件夹全部拖进去 → Commit changes。（更省事：解压 `posebook-v1.zip` 后整个拖入。）

### 第 4 步：部署 PWA 到 GitHub Pages

1. 进入仓库 `posebook` → **Settings** → 左侧 **Pages**
2. **Build and deployment** → **Source** 选 **Deploy from a branch**
3. **Branch** 选 `main`，目录 `/ (root)` → **Save**
4. 等 1~2 分钟，页面上方会出现你的站点地址：`https://你的用户名.github.io/posebook/`

### 第 5 步：手机/电脑打开并配置

1. 手机浏览器（推荐 Chrome / Edge）打开 `https://你的用户名.github.io/posebook/`
2. 首次打开会显示引导，点「去设置」
3. 填入：**GitHub 用户名 / 仓库名（posebook）/ 访问令牌（github_pat_...）**
4. 点「保存」→ 显示"连接成功 ✅"即完成
5. 手机浏览器菜单 → **"添加到主屏幕"**，以后就像 App 一样使用

## 二、日常使用

### 收藏一张好照片

1. 打开 App → 「上传」→ 「选择照片」（可多选）
2. 点六维标签（会应用到本次全部照片）
3. （可选）评分、填来源和拍摄要点备注
4. 「上传到图库」→ 自动压缩并存入你的 GitHub 仓库

### 拍摄前检索姿势

- 点「筛选标签」→ 选 **服饰：明制汉服** + **场景：古建** → 所有相关姿势参考全部列出
- 标签面板支持**搜索与折叠**：顶部输入关键词（如"回眸"）即时过滤 90+ 标签；点维度标题展开/收起，也可一键"展开全部"
- 或直接搜索框输入关键词（如"回眸"、"逆光"）
- 点开任意一张可看大图、改标签、记备注

### 大图学习

- 大图模式支持 ← → 键翻页（手机点两侧箭头），逐张学习动作/角度

### 数据备份

- 设置页 → 「导出备份」下载 `tags.json`，随时可「导入备份」恢复

## 三、⚠️ 隐私与版权提醒（请务必阅读）

你的仓库是**公开**的（GitHub Pages 免费托管要求公开仓库），仓库里的**压缩参考图对全世界可见**。因此：

1. **只存放可公开分享的参考图**——穿搭、姿势、场景、光影等学习素材；
2. **不要存放**含他人隐私的人像照、证件照、聊天截图、私人照片；
3. 收藏他人作品仅供**个人学习参考**，请尊重原作者版权，勿用于商业用途；
4. 如果你需要完全私密的图库，请改用其他自托管方案（如 Immich + 私有部署），本工具不适用。

## 四、原理与注意事项

| 项目 | 说明 |
|---|---|
| 照片存哪 | 压缩后的参考图（约 100~200KB/张）存在你的 GitHub 仓库 `photos/` 目录 |
| 标签存哪 | `data/tags.json`（纯文本，可随时导出） |
| 图片加载 | 走 jsDelivr CDN（`cdn.jsdelivr.net`），国内大部分网络可用；失败自动切换 GitHub 直链 |
| 原图建议 | 原图较大，建议按主题存到百度网盘，仓库里保留压缩参考图即可 |
| 容量 | GitHub 免费仓库上限 1GB（含历史），2000 张压缩图约 300MB，余量充足 |
| 多设备 | 同一时间尽量只用一台设备打标，避免标签互相覆盖 |
| 令牌安全 | 使用"仅授权该仓库 Contents 读写"的受限令牌，即使泄露也只影响该仓库 |
| 令牌过期 | 过期后到设置页更新令牌即可，照片不受影响 |

## 五、常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 手机打开页面空白 / 一直"加载失败" | ① 检查设置里的用户名/仓库名/令牌是否正确（可点「测试连接」）；② 检查手机网络；③ 令牌过期了（去 GitHub 重新生成并更新） |
| 图片显示"加载失败"灰块 | jsDelivr 国内个别时段不稳定。App 已内置 **4 个 jsDelivr 镜像 + GitHub 直链自动切换**，仍失败多半是网络问题，稍后重试或换网络 |
| 保存时报"数据在其他设备被修改" | 另一台设备同时改过标签。App 已自动刷新，重新操作即可。平时尽量同一时间只用一台设备打标 |
| 上传失败提示已上传但未记录 | 图片文件可能已进仓库但标签未保存。重新上传一次即可（仓库里会多一个无人引用的图片文件，不影响使用，可忽略） |
| 上传图片后想恢复原图 | 压缩参考图存仓库，原图请自行备份到百度网盘 |
| 想换仓库 / 换令牌 | 设置页直接改并保存即可，标签数据在新仓库不存在时会自动重建空库 |
| 每次打开都要重新设置（配置丢失） | 手机浏览器在关闭时清除了网站数据。① 治本：浏览器设置里关闭"退出时清除浏览数据"类选项；② 兜底：设置页 →「复制配置」存入备忘录，丢失后点「粘贴恢复」5 秒找回 |
