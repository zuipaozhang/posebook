备份与数据

你的照片和标签都存在自己的 GitHub 仓库里。这里可以下载/恢复标签数据。

「复制配置」：存备忘录，丢失后「粘贴恢复」；
「生成配置链接」：链接自带配置，用它打开并重新添加到桌面，之后不保留浏览器记录也不怕。

使用说明

  1. 收藏：看到好看的照片 → 「上传」→ 选图 → 点标签 → 上传。图片自动压缩存入你的 GitHub 仓库。
  2. 打标：按 服饰 / 场景 / 动作 / 角度 / 构图 / 光线 六维点选，也可以在大图里改。
  3. 检索：搜索关键词，或点「筛选标签」组合多个标签（如 明制汉服 + 古建），拍摄前快速看姿势参考。
  4. 原图备份：仓库存的是压缩参考图；原图建议按主题存到百度网盘。
  5. 多设备：同一时间尽量只用一台设备打标，避免标签互相覆盖。
